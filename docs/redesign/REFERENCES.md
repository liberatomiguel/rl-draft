# UI references from Miguel (2026-11-17)

Fifteen images Miguel sent as **references only**: ideas to learn from, nothing
to copy. The images are not in the repo (third-party work); they came in
`REFERÊNCIAS UI.zip` in his Downloads folder.

His framing, which overrides anything a reference suggests: the game keeps its
own identity, an **RLCS broadcast desk, set in Industry, in blue and orange,
premium and minimal, held to every anti-slop principle**. `DESIGN.md` stays the
law. A reference is used for structure and behaviour, never for its finish.

## What the set has in common (and we already share)

One accent on a near-black ground, hairline frames, dense tables with a clear
row state, condensed caps section heads, real numbers set large, and a
**stage**: one framed area that hosts the main object (a card, a pitch, a
scoreboard) with its controls clustered right under it.

## What the references do that we do not

Named so nobody imports it by accident. Each one is a pattern the anti-slop
rulebook lists and `DESIGN.md` forbids:

- Neon gradient borders with a halo around a card (two of the images). Our
  state is a coloured hairline, no halo. Glow belongs to rarity and rewards.
- Purple and violet gradient dashboards, tinted glass panels.
- The default shell: sidebar, a row of four stat cards with green deltas, a
  chart, a table. Here a screen is built around its one decision.
- A grid of identical team or feature cards each ending in "View →".
- An emoji in a greeting, "Upgrade" upsell cards, invented activity feeds.
- Italic display figures. Italic is the Home wordmark's alone.
