### Fixed
- Staging emitted `index, follow` on eight pages: `/play`, `/how-to-play`,
  `/collection`, `/challenges`, `/achievements`, `/privacy`, `/quiz` and
  `/leaderboards`. Root cause: those pages set their own `robots`, and in Next a
  page's `robots` replaces the root layout's, so the NOINDEX build's blanket
  noindex never reached them. Only robots.txt kept crawlers out. Pages no
  longer state `robots` unless they opt out of the index.
- Content pages had no `og:image`, `og:site_name` or `og:type`, and every page
  carried the home page's `twitter:title` and `twitter:description`; the app
  pages carried the home's `og:title` and `og:url`. Root cause: Next merges
  metadata shallowly, so a page's partial `openGraph` replaced the root's, and
  pages with none inherited the home's. One helper (`pageMetadata`) now builds
  the whole block per page.
- `/profile`, `/settings` and `/missions` had the home page's canonical, and
  `/profile` and `/settings` its title. Root cause: `alternates.canonical: "/"`
  in the root layout was inherited by every page without its own, and the two
  pages are Client Components with no metadata. The root canonical is gone;
  both pages got a layout with their own metadata (`/settings` is noindex).
- Layout shift of 0.14–0.35 on a phone on `/collection`, `/profile`,
  `/challenges` and `/play` (0.03–0.13 on desktop). Root cause: those pages
  render from the saved profile after hydration and change height, and the
  footer, in view on first paint, moved with them.
- The Largest Contentful Paint of a content page was only recorded at
  hydration (4.4 s in Lighthouse mobile, 1.1 s for the home page). Root cause:
  the article sits in a `.rise-in` wrapper whose animation started at opacity
  0, and Chrome does not count a paint at opacity 0 as contentful. The
  animation starts at 0.01.
- Content copy said "84 special cards" (the game has 111), that only SAM was
  region-locked, and that there is no sign-in; `/leaderboards` said "sign in
  with Discord" (it is an email code). The count now comes from the dataset.
- A fresh Windows worktree rewrote 129 manifest hashes (every badge and banner)
  and its build failed "check generated images". Root cause: SVG sources were
  hashed as raw bytes, and a checkout with `core.autocrlf` writes them with
  CRLF. They are hashed with LF line ends; the committed manifest is unchanged.
- The cosmetic unlock pop-up in the root layout imported `sourceLabel` from the
  locker, which put the whole locker modal in every page's bundle.

## 7. Entradas propostas para o DESIGN-DECISIONS (coordenador numera)

- **Footer below the first screen.** `<main>` has `min-h-svh`. The pages that
  render from the saved profile change height when they hydrate; a footer in
  view moved with them (CLS 0.14–0.35 on a phone). Cost: short pages scroll to
  reach the footer.
- **Search-intent content pages and career-only pages.** `PAGE_ROUTES` gains
  `simulator`, `manager`, `fantasy`. `CAREER_ONLY_PAGES` exist only when
  `FEATURES.careerMode`; `scripts/postexport.mjs` deletes their export
  otherwise (`CAREER_LANDING`, keep in sync). Their URLs must not contain
  `/career` (the sitemap rule).
- **One metadata helper.** Every page builds canonical, Open Graph and Twitter
  through `pageMetadata` (`src/lib/contentMeta.ts`); no page sets `robots`
  unless it opts out, so the NOINDEX build's blanket rule holds. The root
  layout sets no canonical.
- **Entrance animation starts at opacity 0.01**, so server-rendered text in a
  `.rise-in` wrapper counts as the Largest Contentful Paint when first painted.
- **No inline CSS.** `experimental.inlineCss` was rejected: it duplicates the
  stylesheet in every HTML and its RSC payload, and returning players lose the
  cached file.
- **Security headers without a script policy.** HSTS, frame policy, COOP and a
  partial CSP live in `public/_headers`; a `script-src` needs nonces, which a
  static export cannot issue.

  `src/lib/contentMeta.ts` e não declare `robots`. O `postexport` falha o build
  se uma página indexável ficar sem canonical próprio, ou se uma página ficar
  sem noindex no build de staging.
