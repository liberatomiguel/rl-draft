## Item 7 — XP do Road to Worlds: valores para o coordenador aplicar

A C1 mediu 700–1.160 XP por temporada de carreira com os valores provisórios; uma run de
draft paga ~500. Alvo: ~10k XP por temporada (uma hora de carreira ≈ uma hora de draft).
Substituir em `CAREER_XP` (`src/config/balance.ts`, branch `v2/C1`):

```ts
export const CAREER_XP = {
  seriesPlayed: 50,
  seriesWinBonus: 30,
  eventFinished: { t3: 100, t2: 150, qualifier: 100, regional: 250, major: 500, worlds: 800 } as Record<string, number>,
  title: { t3: 200, t2: 400, regional: 800, major: 2_000, worlds: 5_000 },
  seasonCompleted: 1_500,
  maxPerWrite: 10_000,
} as const;
```

Conta: ~80 séries com metade de vitórias = 5.200; ~15 eventos = 2.250; temporada = 1.500;
total ≈ 9k sem títulos. Título mundial soma 5.800 com o evento.
**Risco a conferir:** se der para simular uma temporada inteira em poucos minutos, isso vira o
melhor farm de XP do jogo. A C1 descreve a temporada como "uma hora ou duas"; se o avanço
automático for bem mais rápido, corte `seriesPlayed` pela metade. Depois de aplicar: atualizar o
teste `careerV2C1.test.ts` da C1 e o fingerprint de `balanceVersion.test.ts`.

- **Faixas de rank dos Challenges**: mantidas por decisão do Miguel (5 pedem SSL, 3 GC, 6 Champion).
- **Desbloqueios entre temporadas**: coleção ganha fica, taxas e raridades recomeçam pelo XP da
  temporada (confirmado pelo Miguel). É o comportamento atual; nada a mudar.
- **XP do RTW no código**: ver seção acima; `CAREER_XP` não existe neste branch.
- Copy antiga de changelog in-game ("Hard libera no Silver", "Coleção libera no Bronze")
  não foi revisada; nenhuma string nova de interface foi necessária.

## Decisões que tomei sozinho

- 3º e 4º pagam o mesmo no rating; vice é metade do campeão.
- Seleções FIFAe no Gold (15k, ~30 runs): cedo o bastante para o casual ver na semana 2.
- `creator`, `wings` e `community` passam a valer a partir do Silver, junto com a primeira raridade.
- Chance de especial no Diamond 6% → 5% e Champion 9% → 8% (rampa mais suave numa escada mais longa).
- Conquistas de desafio, seleção e quiz são concedidas por `awardAchievements` nos pontos em que
  o resultado é gravado (`runStore` para desafio e fim de run, `profileStore` para o quiz), não
  no avaliador de contadores, para não importar o dataset no caminho compartilhado.
- As conquistas de rank novas (Diamond, Champion, GC) também entram no backfill de saves
  antigos, que lê o XP guardado contra a curva nova: quem tinha 75k+ de XP na pre-season pode
  recebê-las na migração.
- Um jogador novo ganha ~1.500 XP em conquistas comuns nas primeiras runs; chega ao Silver mais
  cedo do que só pelas runs.
- Não mexi na distribuição de `cosmetics.ts`: a trilha de rank da Season e o badge Dynasty
  (SSL + 3 Mundiais + 25 títulos Legacy numa temporada) seguem a curva nova sem edição.
